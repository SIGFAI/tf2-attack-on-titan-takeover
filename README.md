# Attack on Titan Takeover

**Team Fortress 2** × Attack on Titan · visual · idea by the team

Bring Attack on Titan into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> TF2 bots grow into giant Titans and the green-cloaked RED team grapples to their napes. A Titan Heavy stomped me flat.

## Install

Copy the mod folder's contents into your Team Fortress 2 tf folder (the scripts folder), then start a local server with bots on any map and load the mod's script at map start.
